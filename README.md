#  Mind the Mic — A Text to Speech Converter

*its simple ^-^ You type, it talks!*

One of my early experiments with **React Native and Expo**, just starting to explore building applications beyond the little JavaScript games I'd been making.

The idea was simple — type something into a text box, press a button, and have the app read it aloud. Honestly, hearing my own code *talk back to me* for the first time was pretty exciting!

###  Built With ummmm

- **JavaScript** — Application logic
- **React Native** — Building the app interface
- **Expo & Expo Snack** — Developing, previewing, and testing the app
- **Expo Speech** — Text-to-speech functionality

###  What I Learnt :)

This project introduced me to a completely different side of JavaScript!

- **React Components & JSX** — Building an interface using reusable UI elements instead of drawing everything manually.
- **State Management** — Using `this.state` and `this.setState()` to remember and update whatever the user typed.
- **Event Handling** — Using `onChangeText` to detect typing and `onPress` to trigger an action.
- **Props & Styling** — Passing values to components and designing the interface using React Native's `StyleSheet`.
- **External Libraries** — Using `expo-speech` to access the device's text-to-speech functionality.
- **React Native vs p5.js** — Understanding how event-driven applications differ from the frame-based animations and games I'd built before.

It was fascinating to go from making sprites move around a screen to building an app that could actually speak!

### how to runnn

This project was originally created using **Expo Snack**, an online playground for React Native.

To explore or test it:

1. Open [Expo Snack](https://snack.expo.dev/).
2. Open `App.js` and paste in the project's source code.
3. Add the required dependencies, including `expo-speech` and `react-native-elements`.
4. Preview the interface using the web, Android, or iOS options.
5. To test it on your phone, install [Expo Go](https://expo.dev/go), select **My Device** in Snack, and scan the generated QR code.

**Note:** The original project built in 2020 uses Expo SDK 38. Running it with modern Expo Go may require updating its dependencies and making minor code changes.
